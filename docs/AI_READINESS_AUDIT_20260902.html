一、P0 事故：KB 问答引擎全量 miss（本轮发现并修复）

根因链（三连环）：
① kb_fts 使用 unicode61 分词器——整段中文作为单一 token，"超标排放"能命中但"超标"永远打不中；
② kb_qa 查询 SELECT 带 category 列但 FTS 表没有该列 → OperationalError 被 except 静默吞掉 → 恒走兜底；
③ LIKE 兜底只取第一个切词（如"COD"）单查 → 命中的全是内部文档被噪声过滤排除 → 最终 miss。
修复：FTS 重建为 trigram 分词器（273/273 全同步，修复前 231/273）+ 混合检索（≥3字词走 FTS 毫秒级，2字词走 LIKE）+ query 参数兼容。
