一、核心结论

「超级环保智能体」不是把 62 个页面再翻一倍，而是换一个组织方式：从「按功能堆页面」升级为「按人组织服务」——每一类环保从业人员进来，看到的都是为自己量身定制的端到端工作台：一句话问出答案、一次点击完成培训、一次拍照完成检查、一个申请拿到脱敏研究数据。

路径上坚定智慧化：用 KB-first 知识问答做全员统一入口（秒回、有出处），用 本地垂直模型做专业深度，用 多模态视觉做执法现场智能，用 智能体编排做多步任务自动化——正好复用本机已有的平台能力（视觉引擎、微调管线、实时交互引擎），不重复造轮子。

三、端到端服务矩阵：一个人 × 一条完整链路

端到端 = 输入 → AI 处理 → 输出 一条链走完，中间不换工具。以四类典型用户为例：

用户输入AI 处理（智能化路径）输出（直达结果）
执法人员一张现场照片 + 一句描述视觉识别违规要素（L4）→ KB 匹配法条（L2）→ 裁量计算（L1）→ 文书生成检查笔录 + 处罚文书初稿（现场 5 分钟拿走）
企业 EHS「帮我做本月自查」行业画像 → 自查清单生成 → 台账数据核验 → 风险评分自查报告 + 整改清单 + 执行报告草稿
科研人员数据申请（研究目的+范围）资质核验 → 数据分类分级 → 自动脱敏（k-匿名）→ 水印溯源脱敏数据集下载链接 + API 密钥 + 引用格式
学员「我要考执法证」知识图谱 → 个性化学习路径 → 练题 → 错题辨析（SFT 模型）学时证明 + 模拟成绩单 + 薄弱点图谱
用户强调的四大场景在矩阵中的位置：知识问答 = 全员入口（L2 RAG）；培训学习 = D17 学员闭环；执法检查 = A1 移动执法闭环；脱敏数据研究 = D15 数据开放服务。四个场景分别在一期、二期、二期、二期落地。

四、智能化五级路径（坚定的智慧化路线）

现状 · 已有
L1 规则引擎
关键词匹配案情分析（smart_analyzer）、阈值预警（smart-alert）、裁量查表（penalty-calculator）。快但笨，只覆盖结构化场景。
一期落地
L2 RAG 知识问答（全员统一入口）
KB 从 70 条扩到 500+ 条（35 部法规条目级拆解 + 106 案例结构化 + 标准规范）；FTS5 检索 + 三级分级（≥0.7 直答 / 0.4-0.7 摘要润色 / <0.4 AI 兜底）；答案带出处条目。本地算力优先，P95 < 1.5s。
二·三期落地
L3 环保垂直模型（本地微调）
复用已跑通的微调管线经验（数据集 → SFT/DPO → 评估 → 达标上生产，七条修真教训）：构建「环保问答评测集」（对标 BaziQA 模式），Qwen2.5-7B 本地微调出环保专用模型，覆盖法条理解、案例推理、文书语言。训练数据全部来自自有 KB——知识三化闭环（模型化/结构化/口语化）。
三期落地
L4 多模态执法视觉
现场照片/视频 → 违规要素识别（暗管、渗排、露天堆放、冒黑烟…）→ 与 KB 违法情形匹配。接平台母引擎视觉能力（HTTP API 调用，板块不越界），识别结果回填执法链路。
四期落地
L5 智能体编排（超级智能体形态）
一句话委托 → 多步任务自动执行：「跟进昨天那个举报」= 拉取举报 → 派单执法 → 生成检查任务 → 结果回写 → 通知举报人。任务流引擎 + 工具调用 + 人工卡点（关键决策留人）。

五级不是替换关系，是叠加关系：L1 干结构化、L2 干问答、L3 干深度推理、L4 干看、L5 干串联。每一级都为上一级兜底。

五、目标架构：按人组织的三层服务架构

👤 角色层
22 类人员工作台
每类人员一个专属工作台（角色路由：登录即达），工作台 = 该角色的 服务卡片集合（问答/培训/执法/数据…按需组合）。现有 62 页面拆解重组成卡片，按角色重新分发。
🧠 智能层
L1-L5 能力栈
统一问答网关（KB-first 三级分级）+ 本地垂直模型（环保 7B）+ 视觉识别（调平台视觉引擎 API）+ 任务编排引擎（L5）+ 培训学练考评引擎 + 数据脱敏引擎。
📚 知识与数据层
自有 KB（kb_formal：法规条目化 + 案例结构化 + 标准 + 裁量基准，70 → 500 → 2000 条，staging→审核→formal 流水线）+ 业务库（案例/监测/企业/许可）+ 脱敏研究数据集（对外开放层）+ 训练数据（SFT/DPO，来自 KB 与反馈回流）。

边界红线（不变）：视觉/训练引擎用平台母引擎的，HTTP API 调用；环保领域知识归本项目自有库；品牌/数据/部署三隔离。

六、脱敏数据研究服务（重点新建）

为科研人员（D15）和高校（D16）提供的合规数据开放能力，是「研究」场景的核心：

数据域脱敏规则开放形式
执法案例（106 例）企业名→代称哈希；人名/电话→删除；坐标→区县级模糊研究数据集（JSON/CSV）下载 + 申请审批流
在线监测数据（iot_data）企业标识→分组代号；数值保留（研究必需）；时间→日期粒度聚合统计 API + 数据集下载
企业环境行为k-匿名（每条记录至少 k=5 相同准标识组）批量研究数据包（带水印溯源 + 引用格式）

合规基线：数据分类分级（公开/内部/敏感）、申请-审批-留痕全流程、个人信息保护法与数据安全法红线预检、每个数据集带使用协议。第三方需要商业数据的走订阅（商业化出口）。
