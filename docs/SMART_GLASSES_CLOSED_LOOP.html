我们是智能体，要极致 AI 化。后续规划智能眼镜，通过实时采集 + 实时交互，指导一窍不通的从业人员以专业水准完成闭环工作。

1 战略定位

从「人人可问」到「人人有事干」，再到「人人戴着眼镜也能干专业活」——智能眼镜不是新增功能，而是把既有 AI 能力（视觉识别 + KB 推理 + 语音播报）装进从业者的眼睛和耳朵。

3 外行变专业 · 五大场景

🔍 现场执法

眼镜看到排污口 → AI 识别设备/工况 → 自动比对排污许可证/历史监测数据 → 眼镜念出「该检查 X 因子，现在做 Y，问题在 Z」。

角色：gov_enforcement · 现场 5 分钟出清单

⚙️ 监测站运维

眼镜对准监测仪器 → AI 读屏 → 判断超标/异常 → 提示「参数漂移，建议校准」。

角色：监测运维 · 让小白会守站

🏭 企业巡检

眼镜扫车间 → AI 识别风险点 → 实时给「现在去 X 确认 Y，记得戴 Z 防护」。

角色：enterprise · 企业环保员自检

🚨 应急处置

眼镜直播现场 → AI 给「泄漏物质 X，疏散半径 Y 米，处置方案 Z」。

角色：应急处置 · 危机时刻不慌乱

📢 公众监督

眼镜拍到排污 → AI 识别 → 自动生成举报材料 + 推送监管端。

角色：public · 人人都是监督员

4 实施路线

沿「极致 AI 化」五阶演进，与一期二期承接。

阶段能力状态说明
一期人人可问（kb_qa 问答引擎 + KB 三级分级）已完成AI 直答前置能力，闭环的地基
二期人人有事干（执法/培训/审批工作流）进行中闭环的「事」层，正推进
二期+智能眼镜接入层（采集 SDK + 视觉编排 + TTS + 场景模板）待启动闭环的「实时」层，本次战略核心
三期穿戴入口落地（Rokid 选型 + 现场试点）待启动端到端延迟 P95 < 1.5s

5 关键判断

✅ 复用优先

视觉（8913）、KB（kb_qa）、语音（8912）全部已有，眼镜层只做编排，不重复造轮子——符合「能力复用矩阵 · 一个算法多端服务」。

⚡ 实时是命脉

现场作业最怕「卡壳」，端到端 P95 < 1.5s 是硬指标；KB 命中 ≥0.7 直答优先，本地算力兜底。

🧭 AI 主导不背锅

关键动作 AI 给方案、人确认执行；涉及执法/处置的结论自动留痕可追溯，符合「医疗/命理式脱敏 + 关键时刻应急」纪律。

🔐 隐私边界

眼镜实时采集须遵循「全面全量实时 + 隐私法律边界」：本地优先存储、传输脱敏、采集范围合规。
