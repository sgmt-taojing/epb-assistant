数据怎么拿（端到端流程）

所有研究数据均经过分类分级 + 自动脱敏 + 溯源水印后开放。申请需说明研究目的与数据范围，审批通过后获取下载链接或 API 密钥。全程留痕，符合《数据安全法》《个人信息保护法》要求。
